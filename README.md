# Lets Hang Out!

Un refugio pixel art para conversar con amigos, pescar y escuchar música junto a la fogata.

## Descargar para Windows

[Descargar el launcher de Lets Hang Out!](https://github.com/omdiaz-code/Let-s-Hang-Out-/releases/latest/download/LetsHangOut-Setup.exe)

Instala el launcher y ábrelo. Descargará el juego y buscará actualizaciones automáticamente. Tus partidas y ajustes se conservan al actualizar.

Este repositorio distribuye las versiones del juego y el canal de actualizaciones. Los archivos de desarrollo y los originales editables se conservan por separado.

Las actualizaciones se verifican con una firma digital antes de instalarlas. No se requiere una cuenta de GitHub para jugar.

El arte, los sonidos y demás contenido pertenecen a sus respectivos titulares. Su descarga no concede permiso para reutilizarlos; las licencias de componentes externos se incluyen en el juego.
